# صقر — جزء الذكاء الاصطناعي والباك إند

أكواد موديل كشف الأصوات المزيفة والمستنسخة (SAQR v2.2) والـ API الذي يستقبل الملف من الموقع ويرجع الحكم.

## المجلدات

| المجلد | المحتوى |
|---|---|
| `backend/` | الـ API (FastAPI): `app.py` يستقبل الملف ويحفظ النتيجة في قاعدة بيانات SQLite، و`saqr_core.py` منطق التحليل، وملفات التثبيت والتشغيل على ويندوز |
| `training/` | تدريب نسخ v2 وv2.1 وv2.2 على Kaggle (GPU)، وضبط حدود القرار، وتجهيز الموديل النهائي |
| `data_generation/` | توليد أصوات مستنسخة للتدريب والاختبار (kNN-VC وChatterbox) |
| `evaluation/` | الاختبارات: أدوات استنساخ لم يرها الموديل (OpenVoice وChatterbox)، وأصوات جوال حقيقية (Common Voice)، وأصوات سعودية منخفضة الجودة (SADA)، والموسيقى الخلفية |

## التشغيل (ويندوز)

1. تثبيت Python 3.11 وffmpeg.
2. وضع مجلد الموديل `saqr_v22_final` داخل `backend/`.
3. تشغيل `setup.bat` مرة واحدة، ثم `run.bat` لتشغيل السيرفر، و`tunnel.bat` للرابط العام.

## ما لم يُرفع

- **ملفات الموديل** (1.2 جيجابايت): أكبر من حد GitHub للملف الواحد (100 ميجابايت).
- **البيانات** (ArFake وSADA وCommon Voice والأصوات المستنسخة): رخص بعضها تمنع إعادة النشر.
- **قاعدة البيانات `saqr.db`**: سجلات الاستخدام الفعلي.
